# SlackBot

A custom Slack bot featuring interactive slash commands and API integrations. Built to experiment with connecting external APIs to Slack and creating useful, entertaining commands.

## Features

The bot includes several commands:

- **Random Art** – Returns a random piece of artwork.
- **Random Color** – Generates a random color.
- **Random Cat** – Fetches and displays a random cat image.
- **Command Help** – Provides access to the available commands and usage information.

## Usage

1. Open your Slack workspace.
2. Type `/legen` into the message box.
3. Select one of the available commands.
4. Run the command to receive its result.

## Development

One of the main challenges of this project was finding suitable APIs for the different command ideas. Connecting external services and making their responses work within Slack was an important part of the development process.
