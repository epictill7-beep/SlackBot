# Commands
In the end the commands do work
  - The random art provides a random piece of art
  - The random color provides a random color
  - The cat image command provides a random cat image
these I consider to be the main commands since the others are just to get the list of commands and such.

## Using the Commands
to use the commands you just do /legen in slack and the commands for legen come up.
